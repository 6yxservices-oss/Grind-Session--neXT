# MVP Fan Platform — Strategy Pack

Three deliverables for Ryan Rechten / MVP Partnerships, built around the MVP fan engagement platform and Dropt analytics dashboard.

| File | Audience | Purpose |
|---|---|---|
| `00-ryan-one-pager.md` | Ryan Rechten / partnerships | Direct one-page answer to Ryan's original question — distilled from the rest of the pack |
| `01-sponsor-sales-sheet.md` | External sponsors | One-pager Ryan can send to brands to sell platform-native sponsorship packages |
| `02-cmo-deck.md` | Internal MVP leadership | 6-slide deck framing the platform as a CMO operating model |
| `03-launch-checklist.md` | Internal ops team | 14-day pilot plan with owners, dates, success criteria, risk register |
| `04-sponsor-pitch-email.md` | Ryan → sponsor targets | Three drop-in email templates (beverage, sportsbook, lifestyle DTC) with sending checklist |
| `05-cmo-deck-speaker-notes.md` | Whoever presents the deck | Slide-by-slide talking points, anticipated interrupts, full Q&A bank |
| `06-ryan-walkthrough.html` | Ryan + sponsors + design review | Visual point-and-show walkthrough: fan flow on the left, MVP data capture on the right. Open in any browser; print to PDF. Self-contained, no dependencies. |
| `07-ryan-walkthrough.docx` | Ryan, internal stakeholders | Word doc version of the walkthrough — same content, paginated for sharing/editing. Generated from `scripts/build-docx.py`. |

**Product framing:** Throughout the pack, the platform is called **Club MVP** — positioned as the logged-in fan layer on top of the existing [mostvaluablepromotions.com](https://www.mostvaluablepromotions.com/) site, not a separate destination.

**Headline thesis:** MVP currently rents fan attention from third-party platforms. The fan engagement platform + Dropt converts that attention into a first-party, opted-in, retargetable audience that compounds fight after fight — turning every event into year-round revenue and unlocking a new tier of measurable sponsorship inventory.
